# Qiongli v2.6.2 — Plugin installation fixes

This patch improves interactive installation and upgrades in Codex, Claude Code,
and DeepSeek Harness.

- **Codex:** Give the full Plugin inventory up to 75 seconds so Codex can finish
  reading the remote account inventory. Report the exact inventory command or
  configuration request on failure. Return when migration times out, even if a
  helper still holds a pipe. Conflict checks and approvals still apply.
- **Claude Code:** Show each enabled conflicting Qiongli Plugin ID and its scope.
  For a user entry, print a scoped command to disable it. Codex and Claude Code
  exports now also accept the default Host-specific source directories.
- **DeepSeek Harness:** Ship the prebuilt npm package without the automatic
  `postinstall` review so pnpm can install it under strict script policy. If the
  official manager reports an error, the CLI checks the selected profile and
  reports any verified installation while preserving the command failure.
  Run `qiongli install migrate --interactive` for the optional migration review.

The CLI also clarifies local installation status and pending research checks.
Project command help points to the saved-document read commands.

2.6.2 修复 Codex 安装读取插件清单提前超时的问题，Claude Code 会列出旧插件的 ID
及作用域，DeepSeek Harness 安装则无需批准穷理的自动迁移脚本。安装仍由各客户端的
官方管理器处理。CLI 也补充了本机安装状态和已保存文档的提示。

Upgrade the CLI through its original installation channel, then update only the
Host Plugins you use. Open a new session and check the Qiongli Skills and
`qiongli_config_status`. The [installation guide](../../docs/advanced/plugin-installation.md)
describes the Host-specific prompts and conflict handling.

The [execution plan](../../docs/superpowers/plans/2026-10-05-v2-4-plugin-quality-release-plan.md#november-18--v262-release-qualification)
records terminal, package and policy checks. The release workflow qualifies the
exact tag across macOS ARM64, Windows x64 and Linux x64/ARM64. The maintainer
will verify the actual macOS Host upgrades separately.
