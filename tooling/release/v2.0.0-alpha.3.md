# Qiongli v2.0.0-alpha.3 Community Alpha

Status: prerelease candidate; publication requires exact-source Native CI,
target-native acceptance, protected authorization, and final trust-bundle review.

状态：预发布候选版本；公开发布前必须完成同一源码提交的 Native CI、目标平台原生验收、
受保护授权和最终信任包复核。

## What this Alpha provides / 本 Alpha 版本提供的能力

- Deterministic Academic Graph v1 over supported canonical research artifacts,
  with shared App, CLI, and Full MCP read contracts.
- Bounded project continuity, artifact inspection, captures, claim-evidence
  coverage, provenance, and native stale-state diagnostics.
- Dependency-free native CLI and desktop App with receipt-backed install,
  verify, repair, remove, predecessor restore, and shell PATH configuration.
- Managed Codex and Claude Code integration with structured install guidance,
  version probes, positive activation/MCP observation, and fail-closed status.
- Embedded academic Skills plus bounded Lite and Full MCP research surfaces.

- 针对受支持 canonical research artifacts 的确定性 Academic Graph v1，并由
  App、CLI 和 Full MCP 共享同一套只读契约。
- 有边界的项目连续性、artifact 检查、captures、claim-evidence 覆盖、provenance
  和原生 stale-state 诊断。
- 不依赖用户安装 Rust、Python 或 Node.js 的原生 CLI 与桌面 App；提供带 receipt 的
  安装、校验、修复、删除、前序文件恢复和 shell PATH 配置。
- 受管理的 Codex 与 Claude Code 集成，包含结构化安装指引、版本探测、激活/MCP
  正向观察，以及默认失败关闭的状态判定。
- 内嵌学术 Skills，以及有边界的 Lite/Full MCP 研究入口。

## Install and compatibility / 安装与兼容性

Use the native 2.x guide in `docs/alpha/install-2x.md`. npm, Python, and shell
installers documented elsewhere are the maintained legacy 1.x line and do not
install this native product.

请使用 `docs/alpha/install-2x.md` 中的原生 2.x 安装指南。其他位置记录的 npm、
Python 和 shell installer 属于继续维护的 1.x 旧版，不会安装本原生产品。

Validated client floor and current test versions:

- Codex CLI: minimum `0.144.1`; tested with `0.145.0`.
- Claude Code: minimum `2.1.206`; tested with `2.1.220`.

After Qiongli prepares a managed local source, the Host still owns plugin
installation/enabling, trust prompts, cache, and reload. Follow the exact
commands shown by the App or the structured snapshot from `qiongli app snapshot`; do not infer success
from files alone.

Qiongli 准备好受管理的本地 source 后，plugin 的安装/启用、信任提示、缓存和 reload
仍由 Host 管理。请执行 App 或 `qiongli app snapshot` 结构化快照显示的精确命令，不要仅根据
文件存在推断安装成功。

## Platform trust / 平台信任边界

- macOS arm64: Community Alpha DMG/update ZIP is ad-hoc signed and not
  notarized. Gatekeeper may require the per-app **Open Anyway** flow.
- Windows x86_64: the portable directory is not Authenticode signed and may be
  warned about or blocked by SmartScreen, Smart App Control, antivirus, or
  enterprise policy.
- Linux x86_64: the AppImage and portable CLI require the facilities declared
  by the advertised package.

- macOS arm64：Community Alpha DMG/update ZIP 采用 ad-hoc 签名且未公证；
  Gatekeeper 可能要求针对该 App 执行“仍要打开”。
- Windows x86_64：portable directory 未做 Authenticode 签名，可能被
  SmartScreen、Smart App Control、杀毒软件或企业策略警告或阻止。
- Linux x86_64：AppImage 与 portable CLI 需要系统提供产物声明的运行条件。

Do not disable global operating-system security controls or import a
self-signed Windows root certificate.

请勿关闭全局操作系统安全机制，也不要导入自签名 Windows 根证书。

## Explicit non-claims / 明确不承诺的范围

- No arbitrary-directory, free-prose, or BibTeX heuristic graph inference.
- No unrestricted Full MCP mutation, unbounded ToolHost execution, or cloud/web
  execution. The only Full MCP project write is the previewed, digest-bound,
  explicitly approved `qiongli_project_capture_apply` operation.
- No Claude Desktop, Codex Desktop, or ChatGPT Marketplace bypass.
- No production OS publisher trust or Stable eligibility.
- Automatic updates are enabled only when separately published signed update
  metadata has target-native acceptance; otherwise use the documented manual
  replacement and rollback path.

- 不提供任意目录、自由文本或 BibTeX 的启发式图推断。
- 不提供不受限的 Full MCP mutation、无边界 ToolHost 执行或云端/网页执行。Full MCP
  唯一的项目写入是经过 preview、digest 绑定和明确批准的
  `qiongli_project_capture_apply`。
- 不绕过 Claude Desktop、Codex Desktop 或 ChatGPT Marketplace。
- 不具备生产级操作系统发布者信任或 Stable 资格。
- 自动更新仅在另行发布的签名 update metadata 已通过目标平台原生验收时启用；
  否则使用文档规定的手动替换与回滚路径。

## Verification and rollback / 验证与回滚

Verify every download against the attached SHA-256 inventory, CycloneDX SBOM,
SLSA provenance, public release authority, signed Community Alpha integrity
record, and exact-set publication authorization. Installation mutations are
receipt-backed; drift, ambiguous ownership, or an incomplete receipt chain
fails closed. Removal restores an authenticated predecessor only when its exact
digest is retained and the installed target has not drifted.

请使用随 release 附带的 SHA-256 清单、CycloneDX SBOM、SLSA provenance、公开
release authority、签名 Community Alpha integrity record 和 exact-set publication
authorization 验证下载。安装变更由 receipt 约束；检测到漂移、所有权不明确或 receipt
链不完整时会失败关闭。只有在保留前序文件精确 digest 且当前安装目标未漂移时，删除流程
才会恢复已认证的前序文件。
