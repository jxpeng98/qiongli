# 选择研究任务

在 Host 中直接提出请求，说明材料与目标即可。下面的句子可以作为起点。

| 目标 | 示例请求 |
|---|---|
| 收窄选题 | 根据这些来源收窄研究问题，指出未解决的假设。 |
| 阅读论文 | 阅读这篇论文，说明方法、发现、证据位置与局限。 |
| 文献综述 | 先拟检索方案，再从已有论文提取证据并综合。 |
| 研究设计 | 检查设计是否符合问题、可用数据与已批准协议。 |
| 写作 | 根据已确认的分析写这一节，保留数字、来源与不确定性。 |
| 研究代码 | 按这份方法说明实现代码，检查统计有效性与可复现性。 |
| 投稿与修稿 | 将审稿意见对应到稿件位置，逐项提出回应。 |
| 修复一条问题 | 解决这个候选中的 I8:P1-01，仅检查受影响的结果。 |
| 阶段交接 | 总结这一阶段，保留来源、决定、变化与待解决问题。 |

## 选刊

已经选定期刊时，请核查其当前要求；需要推荐时，先提供稿件供判断。见[选刊与投稿前审阅](using-agent-skills.md#journal-fit-and-pre-submission-review)。

## 保存与继续

正式项目通过预览、批准和版本校验保存。沿用论点 ID、引用键和来源位置，保留方法限制。总结不会删除原文件，清理由你自己选择和执行。

只想讨论时，用[仅回复](../advanced/agent-skill-collaboration.md#reply-only)。任务编号和产物见 [Skills 参考](../reference/skills.md)，完整研究路线见[论文类型示例](../examples/paper-type-playbooks.md)。
