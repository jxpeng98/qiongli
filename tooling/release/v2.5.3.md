# Qiongli v2.5.3 — native DeepSeek installation and less scrolling

DeepSeek installation now resolves the latest stable npm Plugin, freezes its
exact version for approval, and lets the official DSH manager run with its normal
terminal interaction. The Plugin can differ from the CLI launching installation.

## Installation / 安装

- Query public npm latest metadata before approval; failed lookup stops that Host
  rather than silently using a cached version. Execute
  `dsh plugin --profile <profile> add qiongli@<resolved-version>` without appended
  registry/scripts flags. DSH owns those package policies and download caching.
- Default to `desktop`, requiring an initialized Desktop profile. Explicit web or
  custom profiles remain available; Desktop never silently becomes web. Retain
  PATH discovery and verification of the actual executable behind a `dsh` link.
- Hand package-command input/output to DSH. Its native progress, prompts and errors
  stay visible; Qiongli clears its status first and adds no competing timer or
  package timeout. Version checks and profile initialization remain bounded and
  captured, so initialization does not print the full configuration.
- Hide routine successful stages by default; retain the approval summary, exact
  failure stage and final batch result. `--verbose` expands the plan and twelve
  checks. Qiongli's display flags do not change DSH's native renderer.
- For DSH-only installation, reuse valid saved language or the system locale
  without a separate question; `--language zh/en/auto` overrides it. Keep explicit
  trust, executable/profile rechecks and language-write conflict protection.
- Verify the approved package version and reconstructed source content, avoiding
  false failures caused by comparison with an older CLI's embedded pack. This is
  content consistency; official DSH/pnpm owns registry download integrity.
- Preserve batch continuation after ordinary failures or declined approvals,
  targeted retry commands and interruption handling. Completed changes remain.

安装先查版本、再确认具体命令，下载缓存和进度交给 DSH/pnpm。默认收起成功检查，
减少刷屏和重复语言选择；错误仍保留具体步骤与重试命令。

```sh
qiongli install plugin --target deepseek
qiongli install plugin --target deepseek --language zh
qiongli install plugin --target deepseek --verbose
```

## Compatibility and verification / 兼容与验证

No research-schema migration or model change is introduced. Full/Lite retain
35/15 tools; Codex remains the primary research Host and Antigravity/Pi remain
experimental. Targets remain macOS ARM64, Windows x64 and Linux x64/ARM64
(glibc 2.35+). Twenty-three focused checks cover the preceding implementation,
including a real retained npm bundle and a prompt-driven synthetic PTY. They do
not establish live macOS DSH installation or new-session tool use.

The [execution plan](../../docs/superpowers/plans/2026-10-05-v2-4-plugin-quality-release-plan.md#october-9--253-release-handoff)
records fresh candidate qualification separately. The immutable-tag automation
must qualify all four targets and packages before publishing GitHub assets and
dispatching npm, PyPI and Cargo. Accepted dispatch is not completed publication.

Update the CLI through its original installation channel, then rerun Plugin
installation and start a new Host session. Keep the previous executable, Plugin
sources and research/settings backups for rollback; changing executables does
not reverse research writes. No external Marketplace promotion is included.
