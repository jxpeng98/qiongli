# Main-cohort selection rules

Status: criteria frozen; **actual main task packages not yet selected**.

Select six tasks from actual target workflows, including at least quantitative
and qualitative/interpretive methods. Use publicly shareable original sources
with enough contextual material to independently verify the required conclusions.
Record license/access, exact version, retrieved bytes, table/figure availability
and publication/correction relationships. Do not access private research or fill
missing figures from a caption. A source intended to be partial must be explicitly
partial in all arms. Original images and usable text must be equivalent across
conditions; a C extraction failure cannot quietly reduce what A/B receives.

| Task | Required selection feature | Main outcome |
| --- | --- | --- |
| 1. Single-paper reasoning | Abstract, body and table contribute different necessary facts | Correct, covered, source-supported explanation with access limits |
| 2. Multi-paper synthesis | Three reports with conflicting results or different populations/outcomes; resolve report/study identity | Explain differences without false pooling or vote counting |
| 3. Bilingual editing | Numbers, terms, attribution and qualified conclusions; language-only scope explicit | Preserve meaning and citation support across Chinese/English |
| 4. Correct original | Expert-reviewed adequate prose with no required factual repair | Permit unchanged correct text; avoid added drift and needless work |
| 5. Fresh-session continuation | A real writing unit plus persistent decisions, retained original and unresolved scope | Resume the right task using current material without restating saved context |
| 6. Changed/missing source | A documented correction or missing visual/body portion, with old version retained | Locate affected claims, preserve versions, recover honestly or report the specific remaining blocker |

Assign source packages before seeing treatment outputs. Log previous exposure to
each source/task, overlap with existing repository fixtures, whether it informed
guidance changes, and who designed the review checks. A source/task used to tune
the workflow is development material. A renamed, shortened, translated or
numerically varied version is not automatically unseen. If exposure cannot be
established, label it unknown and exclude it from an unseen-material claim.

Reviewers identify necessary facts and limits against the original sources before
generation. Freeze the checks outside producer access. Checks are not infallible:
retain erroneous criteria and source-backed adjudication, then rescore all affected
arms consistently; do not rewrite a correct answer to fit a mistaken key. A source
correction during execution stops the affected frozen comparison. Restart it as
a separately identified version and retain old attempts and costs.

Main launch requires actual task/source hashes, unchanged runtime settings,
repetition/order manifest, common budgets, reviewer roles, benefit thresholds and
failure rules. Select these before seeing main results. If independent domain
review is unavailable, engineering calibration can continue, but academic-quality
benefit remains unestablished. No user-retention, market-size or commercial claim
can follow from this cohort.
