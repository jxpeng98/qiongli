## Decision

The R3M implementation gate is accepted. One macOS aarch64 local candidate and
one Linux x86-64 CI candidate completed the advertised CLI, embedded skills,
UI startup preflight, Lite MCP, Codex local, Claude Code local, compensation,
removal, and unrelated-state journeys outside the checkout with an empty
runtime `PATH`.

This is not a publication receipt. Both candidates use ephemeral test keys,
their evidence records `publication_allowed: false`, PR #63 remains Draft, and
no `v2.0.0-alpha.1` tag or GitHub Release exists. Production signing,
real-client evidence, displayed-window/accessibility evidence, maintainer
semantic review, and explicit publication authorization remain unresolved.

The later displayed-window review also found that global settings could not be
edited, a Skills destination could not be selected, MCP could not be tested
from the UI, source sessions did not usefully discover Codex or Claude Code,
and no double-clickable cross-platform application artifact existed. Those
failures rebaseline the publication decision: this receipt is retained as R3M
release-core evidence, not as evidence that the Alpha.1 product is ready.
