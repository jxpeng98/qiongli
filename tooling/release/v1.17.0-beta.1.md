## Download Guide

Most users should not download plugin tarballs manually from GitHub's flat asset list.

| You use | Recommended path |
|---|---|
| Qiongli npm/npx CLI (`npm-plugin-lite`) | Use `npx qiongli@next install --target all --project-dir "$PWD"`. |
| Codex (`codex-marketplace-plugin`) | Use `codex plugin marketplace add jxpeng98/skillsplace --ref main` and install `qiongli-next`; no manual tarball download required. |
| Claude Code (`claude-code-marketplace-plugin`) | Use `claude plugin marketplace add jxpeng98/skillsplace@main` and install `qiongli-next`; no manual tarball download required. |
| Claude Desktop direct plugin (`claude-desktop-direct-plugin`) | Download `qiongli-next-claude-desktop-plugin-v1.17.0-beta.1.zip` for direct plugin install. |
| Claude Desktop/Web skills (`claude-desktop-skill-zip`) | Download `qiongli-next-claude-desktop-skill-core-v1.17.0-beta.1.zip` unless you need a different subject ZIP. |
| Claude Desktop literature tools | Download `qiongli-literature-provider-0.1.5.mcpb` and pair it with a Desktop skill ZIP when provider calls are required. |
| Zotero Desktop local writes | Download `qiongli-zotero-companion-0.2.2.xpi` and install it from Zotero's add-on manager when local Zotero search/write support is required. |
| Maintainers | Use Codex/Claude plugin tarballs and Claude plugin ZIPs only for manual marketplace artifact checks or direct Claude plugin upload tests. |

The release also includes `qiongli-downloads-v1.17.0-beta.1.md`, `qiongli-downloads-v1.17.0-beta.1.json`, and `qiongli-artifacts-v1.17.0-beta.1.json` to group the asset list by install surface and expose per-target artifact policy.
