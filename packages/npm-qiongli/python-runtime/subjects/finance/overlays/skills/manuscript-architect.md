## Finance Overlay

When the active subject is finance, apply these additional manuscript constraints:

- State whether the contribution is asset pricing, corporate finance, market microstructure, risk, event-study, theory, or methods.
- Connect each central claim to return construction, benchmark choice, factor exposure, identification, and robustness evidence.
- Separate alpha, mispricing, risk compensation, liquidity, and corporate policy mechanisms.
- For empirical papers, disclose data timing, delisting treatment, event windows, standard errors, and look-ahead bias controls.
- Treat undergraduate-and-above use as acceptable only when the output is raised to doctoral-level journal standards.
