# Qiongli v2.6.3 — Research Skills for GPT-6.2

When you supply enough material, Qiongli can check a manuscript discrepancy,
draft a data availability or ethics statement, or reply to a reviewer directly
in the conversation. Formal project work still uses its existing checkpoints.

- Data availability statements preserve the supplied sharing restrictions,
  including who may access individual records. Ethics drafts distinguish an
  application receipt from the institution's decision.
- Reviewer replies identify which revisions the authors have verified and use
  future tense for agreed work that is still pending.
- The shared workflow uses the primary Skill's routing table. If a project
  changes after you approve a preview, Qiongli requests approval for a fresh
  preview before applying the edit.

2.6.3 改进了材料核对、声明起草和审稿回复。给出相关段落与事实后即可直接取得草稿；

写入前需要重新预览和批准。
