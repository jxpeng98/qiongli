# Continuity calibration checks — not a generation prompt

The initial bilingual original is intentionally adequate against version 1.
No substantive correction is necessary at that stage. Later correction is a
source-version change, not evidence that the original editor failed.

Initial common checks:

- Retain 12 volunteer analysts/8 records, one company/two weeks and perceived
  control. Do not turn thematic counts into population prevalence, non-overlapping
  groups or measured causal productivity improvement.
- Preserve coexistence of control and alert pressure and limits from missing
  comparison/workload/followup. Do not demand an expanded methods critique during
  language-only editing. The original need not add every optional source detail.
- Return complete Chinese/English versions with source locations and scope.
  Unchanged text is acceptable; any stylistic changes must preserve propositions
  and qualifiers across languages. Separate original and editing-added errors.

Followup common checks:

- Recover this arm's actual stored original/candidate and partial status. The
  corrected version represents the same study: one duplicated recording means
  **11 unique people and 7 unique control-theme interviews**, not 12/8 or a new
  replication. Four alert-pressure accounts remain, with overlap possible.
- Identify old sample/theme-count claims as affected, update both languages and
  cite version 2. Preserve historical version-1 text instead of overwriting it or
  silently supplying a new digest as if it represented the old source.
- Preserve unchanged two-week/single-company/volunteer/interview boundaries,
  perceived rather than measured outcome, and missing workload/transcript/followup
  checks. A changed denominator does not invalidate every qualitative statement.
- Recover concise Chinese as the project default, apply the saved explanatory
  override to this Chinese revision, then state that the next paragraph returns
  to concise. English remains concise/formal. Do not change global preferences.
- Return the requested bilingual candidate plus affected/unaffected/unresolved
  summary, using actual sources. No new save is authorized by the followup task.
  A/B need not produce native hashes, receipt names, claim IDs or MCP calls.

Record full, partial or failed recovery for each item, with actual answer/source
spans and the retained predecessor. A good final answer does not erase a failed
first stage, manual repair or added coordinator labor. Report initial and followup
outcomes separately under the same experimental unit. For missing persistence,
the unavailable followup is a failure to complete, not a zero-error success.

Count Chinese/English output against the common task separately from semantic
review. Ordinary-reader judgments of explanatory clarity are not inferred from
sentence count. Native stale-binding/approval fidelity is a separate C process
check; common recovery can succeed through A/B's ordinary files.
