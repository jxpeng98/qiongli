# Frozen forward cohort: substantive argument writing

This two-task cohort uses entirely invented public-style excerpts and a synthetic
own-study record. It tests a complete English literature review and a Chinese
introduction/results/discussion unit, rather than isolated corrected sentences.
The independent authoring packet is `tasks.md` plus `sources.md`; keep
`review-criteria.md` out of the writing context. The packet includes secondary
meta-analysis results, conceptual explanations, positive primary evidence,
comparative findings and realistic missing premises. None represents real
literature, private research or a claimed empirical finding about actual learners.

`fixture-manifest.json` freezes the exact bytes of all four Markdown inputs before
any model trial. Verify its SHA-256 bindings before use. Do not silently replace
these files after observing an answer; an intentional revision needs a distinct
version/cohort identity, retained prior manifest and explicit rationale. Freeze
materialized writing guidance, source revision, Host/model configuration and
capture procedure separately before any future run; this manifest does not
establish that installed guidance was read or that a model was executed.

For each attempted cohort, preserve both task slots and every complete original
answer, actual context, raw execution output and failure/timeout/denial record
before reviewer access to the separate criteria. Missing or failed tasks stay in
the original denominator of two. Retain exact byte hashes and provenance for
captures and reviews. Use the existing journey observation/review owner where
applicable; its structural checks do not decide scientific entailment. Report the
six semantic dimensions separately with answer spans and source locators.

Keep all original verdicts and artifacts. Prompted repairs and repeated attempts
are labelled follow-ups, never replacements or fresh independent cohorts. A
comparison should use the same frozen packet and disclosed execution conditions,
retain both arms' failures, and identify reviewer access to arm identity. These
small synthetic tasks establish only bounded observed writing behavior; they are
not whole-discipline quality, live literature verification, installed-Host
acceptance or a controlled general improvement estimate. No model runs, external
search or project writes are part of fixture creation.
