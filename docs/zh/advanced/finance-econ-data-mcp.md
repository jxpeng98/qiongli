# 金融与经济学数据

Qiongli 的原生文献工具用于查找研究论文，没有内置行情、公司申报文件或经济时间序列 API。
此前提出的 `qiongli_finance_data_status` 和 `qiongli_finance_data_search`
不是已经安装的 Qiongli 2 工具。

研究需要数据时，先确定所需序列或文件、时间范围、版本和访问条件，再使用 Host
实际可用的相应工具，或提供获准使用的文件。研究记录应保留来源、获取日期、数据处理步骤与方法限制。
检索到有关某个数据集的说明，不等于已经取得数据集。

学科档案可以帮助选择方法和报告检查，不需要因此再建一个数据运行时。
工作论文元数据、正式发表版本关联和全文访问也应分别核查。
详见[学科指导](subject-packaging-model.md)与[严谨文献检索](rigorous-literature-search.md)。
