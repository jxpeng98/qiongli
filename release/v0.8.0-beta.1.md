# qiongli `v0.8.0-beta.1` Release Notes

Date: 2026-05-21
Stage: Beta

## Highlights (Draft)

- Adds literature-first Stage B quality gates with mode-aware diagnostics for `targeted_search`, `review_grade`, and `systematic_review`.
- Materializes provider search output into reproducible artifacts: `search_strategy.md`, `search_log.md`, `search_results.csv`, `dedup_log.csv`, and `search_diagnostics.md`.
- Extends B1/B3/B6 project validation so systematic/review-grade literature work cannot be marked complete when diagnostics, provider coverage, known-item recall, snowball coverage, or literature-map evidence are missing.
- Updates citation snowballing and screening to consume search diagnostics for seed rationale, coverage gaps, saturation status, and screening readiness.
- Includes the controller-agnostic execution foundation: solo/duo/triad run metadata, solo role gates, duo handoff artifacts, disagreement handling, and controller-mode offline evals.
- Syncs the portable `qiongli-workflow` package and official plugin mirror for the `0.8.0-beta.1` minor beta line.
