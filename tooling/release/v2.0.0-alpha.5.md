# Qiongli v2.0.0-alpha.5 Community Alpha Test Release Notes

Status: limited public Community Alpha test prerelease. The release uses manual
installation and replacement and does not represent M0, M1, or Stable exit.

状态：范围受限的公开 Community Alpha 测试预发布。该版本采用手动安装与替换，不代表
M0、M1 或 Stable 退出。

## Release scope / 发布范围

- One exact merged `2.x` source produces the macOS arm64, Windows x86_64, and
  Linux x86_64 release set.
- The release includes the current native App and CLI, embedded Plugin/Skills,
  Lite/Full MCP, Graph v1, migration/recovery, Zotero, and installation
  lifecycle for tester feedback.
- Existing Native CI, Community Alpha promotion, protected authorization, and
  offline signing owners are reused. No second release pipeline is introduced.
- Installation, replacement, and rollback are manual. No automatic-update or
  package-manager channel is published.

- macOS arm64、Windows x86_64 与 Linux x86_64 发布集合来自同一个已合并的精确
  `2.x` 源码。
- 发布内容包含当前原生 App 与 CLI、嵌入 Plugin/Skills、Lite/Full MCP、Graph v1、
  migration/recovery、Zotero 与安装生命周期，用于测试反馈。
- 复用现有 Native CI、Community Alpha promotion、受保护授权与离线签名所有者，
  不新增第二套发布流水线。
- 安装、替换与回滚均为手动操作；不发布自动更新或包管理器通道。

## Downloads and trust / 下载与信任边界

- macOS arm64: ZIP and DMG; ad-hoc signed and not notarized. Gatekeeper may
  require the per-app **Open Anyway** flow.
- Windows x86_64: unsigned portable ZIP; SmartScreen, Smart App Control,
  antivirus, or enterprise policy may warn or block it.
- Linux x86_64: AppImage and portable ZIP; the host must provide the runtime
  facilities declared by the package.
- Verify the published SHA-256 inventory and signed integrity manifest before
  installation. Do not disable global operating-system security controls.

- macOS arm64：ZIP 与 DMG；使用 ad-hoc 签名且未公证。Gatekeeper 可能要求对该
  App 执行“仍要打开”。
- Windows x86_64：未签名 portable ZIP；SmartScreen、Smart App Control、杀毒软件
  或企业策略可能发出警告或阻止运行。
- Linux x86_64：AppImage 与 portable ZIP；宿主系统必须提供产物声明的运行条件。
- 安装前请核验公开 SHA-256 清单与已签名完整性 manifest；请勿关闭全局操作系统
  安全机制。

## Qualification / 资格条件

The release is valid only when all of the following bind the same source and
exact bytes:

1. local release readiness passes without publication;
2. explicit full Native CI passes Linux, macOS, Windows, Lite,
   packaged-product, package, and candidate-lifecycle jobs;
3. Community Alpha promotion freshly rebuilds and aggregates the three targets;
4. protected-environment authorization names the exact candidate set;
5. offline Ed25519 signing produces and verifies checksums, CycloneDX SBOM,
   SLSA provenance, bilingual notes, integrity, and authorization receipts;
6. draft inspection and fresh public download verification pass before the
   release is accepted.

只有以下步骤全部绑定同一源码与精确字节后，本版本才有效：

1. 本地 release readiness 在不发布的前提下通过；
2. 显式完整 Native CI 的 Linux、macOS、Windows、Lite、packaged-product、package
   与 candidate-lifecycle jobs 全部通过；
3. Community Alpha promotion 重新构建并聚合三个目标；
4. 受保护环境授权绑定精确候选集合；
5. 离线 Ed25519 签名生成并核验 checksum、CycloneDX SBOM、SLSA provenance、
   双语说明、完整性与授权 receipt；
6. draft 清单核对与全新公开下载验证通过。

## Explicit nonclaims / 明确不承诺的范围

- No production Developer ID/notarization, Authenticode/timestamping,
  automatic update, package-manager publication, official marketplace listing,
  Stable eligibility, roadmap milestone exit, or public announcement campaign.
- Green CI, a merge, or a candidate alone does not authorize publication. The
  protected exact-set decision is separate and expires after 24 hours.
- Historical Alpha 3/4 evidence cannot qualify changed Alpha 5 bytes.

- 不承诺生产 Developer ID/公证、Authenticode/timestamping、自动更新、包管理器发布、
  官方 marketplace 上架、Stable 资格、路线图里程碑退出或公开公告活动。
- 绿色 CI、合并或候选件本身不授权发布；受保护的精确集合决策独立存在并在 24 小时后
  过期。
- 历史 Alpha 3/4 证据不能用于验证变化后的 Alpha 5 字节。

## Replacement and rollback / 替换与回滚

Back up the Qiongli project and global v2 state before testing. Remove only
receipt-owned installed payload during rollback and preserve user projects,
global v2 data, unrelated files, and unmanaged Host state. Published tags and
assets are immutable: withdraw or supersede a faulty prerelease instead of
replacing it in place.

测试前请备份 Qiongli 项目与全局 v2 状态。回滚时只移除 receipt-owned 的已安装
payload，并保留用户项目、全局 v2 数据、无关文件与非托管 Host 状态。公开 tag 与
asset 不可变；发现问题时应撤回或发布后续版本，不得原地替换。

For the general rollback procedure, see `tooling/release/rollback.md`.
