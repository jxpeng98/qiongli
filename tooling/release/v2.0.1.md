# Qiongli v2.0.1

## Patch scope / 补丁范围

This patch candidate repairs distribution auditing and release validation.
It prunes excluded directories before scanning, aligns the current architecture
inventory with accepted decisions, and checks the native CLI release command
and event-scoped legacy publisher guards. Research evaluation tooling also
binds observations and C-to-F continuity checks to captured answers.

本补丁候选修复分发目录扫描与发布校验：扫描前跳过排除目录，对齐现行架构清单，
并核对原生 CLI 发布命令和旧发布器的事件条件。研究评测工具将观察记录及 C→F
连续性检查绑定到实际采集的回答。

## Compatibility / 兼容性

The native runtime and research guidance retain the 2.0.0 behavior, apart from
version metadata. Plugin installation IDs remain `qiongli-next`, and
`plugin-source-status` keeps its existing v1 contract. The stable/Next identity
migration and its v2 status contract remain on the development branch and are
excluded from this patch. Removal of v1 output and migration to the stable Qiongli
identity are planned for 2.1, subject to consumer and target qualification. The native
package remains stable on npm `latest`; the temporary Next Plugin ID does not
select the npm channel. Public Plugins retain their `qiongli-next-<platform>` IDs. Existing Host
configuration and user models are not changed by this preparation.

除版本信息外，原生运行时与研究指导保持 2.0.0 的行为。插件安装 ID 继续使用
`qiongli-next`，`plugin-source-status` 保留现有 v1 契约。正式版与 Next 的标识迁移
及其 v2 状态契约留在开发分支，不包含在本补丁内。

## Upgrade and recovery / 升级与恢复

Upgrade 2.0.0 through the same installation source, verify `qiongli --version`,
then run `qiongli install plugin` to review and update the registered Next source.
Confirm filesystem changes and Host registration separately; start a new Host
session after updating. Keep the prior executable and source receipt. If status
reports drift or an unknown source, stop and retain the files; do not delete the
Host cache or overwrite the source to force an update. Restore the previous
executable/PATH, inspect status, and retry the supported update after resolving
the reported mismatch. A cancelled registration can be retried against the
exported source; local source-current does not prove Host activation.

沿用原安装渠道从 2.0.0 升级，再通过 `qiongli install plugin` 审阅并更新 Next 来源。
保留旧程序与来源收据；遇到漂移或未知来源时保留文件并解决差异，不强制覆盖。
2.1 才计划移除 v1 输出并迁移正式版标识，仍须完成消费者及各平台验证。

本文件是候选说明，不代表已发布。构建验证须绑定确切源码与产物，正式发布需单独授权。
