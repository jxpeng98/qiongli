# Literature synthesis and paper positioning

This targeted regression uses the existing invented Bellhaven packet at
`../writing-quality/sources.md`. It tests a failure pattern identified during
private review of a user-supplied manuscript: brief source summaries displaced by
novelty judgments, feasibility limits and reporting protocols. The manuscript,
its topic, citations and quotations are not part of this fixture.

Freeze the task, draft, source bytes, separate criteria and materialized guidance
before execution. Give the author only the task, draft, sources and relevant
guidance. Preserve the complete first answer before reviewing it against the
criteria; record repairs separately. Reuse the existing research-journey review
owner, with source support distinct from prose/depth judgments.

These sources have already appeared in earlier tests. This is a targeted
regression, not held-out evidence, a controlled improvement estimate, a rewrite
of the private manuscript or an installed-Host observation. No source search,
project creation, research-file write or external publication is required.
