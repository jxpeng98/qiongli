## Verification boundary / 验证边界

The recorded evidence proves only that the exact source passed the full Native
CI jobs and produced a same-source three-target candidate. It does not prove a
signed release, public download, update channel, package-manager distribution,
Stable eligibility, roadmap milestone exit, or announcement authorization.

现有证据只证明精确源码通过完整 Native CI，并生成同源三平台候选；它不证明签名发布、
公开下载、更新通道、包管理器分发、Stable 资格、路线图里程碑退出或公告授权。

The artifacts retain their test trust limits: macOS is ad-hoc signed and not
notarized, Windows is not Authenticode signed, and Linux requires the runtime
facilities declared by its package. They are CI-retained internal evidence, not
public downloads. Do not disable global operating-system security controls to
run them.

产物保留测试信任边界：macOS 使用 ad-hoc 签名且未公证，Windows 未进行
Authenticode 签名，Linux 需要包声明的运行条件。它们是 CI 限期保留的内部证据，不是
公开下载；不得为了运行它们关闭全局操作系统安全机制。
