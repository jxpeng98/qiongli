## Scope

This receipt accepts the maintainer-controlled macOS signing/notarization
entry point and its credential-free CI mechanism test. It does not accept a
Developer ID signature, Apple notarization result, stapled production ticket,
production Gatekeeper assessment, clean-machine launch, human accessibility
journey, or publication.

The entry point takes an external expected source and unsigned package digest,
copies the three exact source files into a private snapshot, and runs the
existing Alpha.1 package acceptance against that snapshot. It signs the nested
canonical executable and launcher before the application, requires hardened
runtime and the fixed bundle identifier, creates a final archive, then
re-extracts that archive and verifies its signature, source manifest, layout,
and post-signing executable hashes. The production branch additionally
requires a Developer ID Application authority, expected Team ID, trusted
timestamp, an `Accepted` `notarytool` result from an existing Keychain profile,
a validated stapled ticket, and a Gatekeeper assessment of the re-extracted
final archive.

The script accepts only Keychain identity/profile references in production
mode. It has no private-key-file, API-key-file, password, credential-creation,
tag, release, install, or publication input.
