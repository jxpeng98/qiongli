## Changes / 变更

- Add native Antigravity CLI Plugin installation and updates through
  `qiongli install plugin --target antigravity`; `agy` is an alias. The generated
  Plugin contains 22 Skill entries, the native executable and Full MCP. Local
  export and official Host registration retain separate confirmation steps.
- Clarify paper-reading evidence scope, allocation/analysis units and verified
  source coverage, with explicit paths for extraction and appraisal guidance.
  Bounded writing preserves reported method detail and checks the requested
  length and format. Reading handoffs identify available and missing material;
  numerical coverage totals require a request and verified source identifiers.
  Project-ID continuation uses the
  existing native revision, receipt binding and document-read owners.
- Strengthen the research observation tools: freeze inputs, preserve complete
  matched tool payloads and failed attempts, bind actual guidance-loading
  evidence, review complete answers and distinguish process exit from task
  success. AGY capture separately checks full results and process cleanup.
- Add a credential-free Codex sandbox preflight that stops on failed execution
  or public guidance reads before any model invocation. Passing this preflight
  does not establish effective Plugin permissions or academic quality.
- Add explicit predecessor selection to package upgrade qualification. The
  distribution workflow checks 2.3.0 separately from historical upgrades, retains
  fixture bytes and records an unavailable predecessor without substituting one.

## Compatibility and rollback / 兼容与回退

CLI, Plugin/Skills and MCP remain the delivery surfaces; Full has 35 tools and
Lite has 15. Users keep their configured models. This release adds no research
schema migration and does not expand project write permissions. Existing
preview, approval, revision/CAS, changed-source and unmanaged-installation
refusals remain in force.

For Antigravity, retain the exported source directory while the Plugin is
registered. Review normal workspace trust and individual tool permissions, then
start a fresh Host session after installation or update. Source export,
registration, discovery and an actual successful call are separate checks.
See [Antigravity installation](../../docs/advanced/plugin-installation.md#antigravity).
IDE and unobserved Host/platform combinations are not qualified by the CLI
adapter. Codex/Claude generated archives and the npm DeepSeek projection retain
their existing distribution owners.

Before upgrading from 2.3.0 to 2.4.0, retain the previous executable, Plugin source and backups
of projects/settings. Test on a project copy. Reverting the executable or Plugin
does not undo project writes or downgrade saved receipt formats; restore a
separate pre-upgrade backup when required. The upgrade checker establishes
package replacement and synthetic fixture retention, not arbitrary data migration.

升级前保留旧程序、Plugin 源目录和项目配置备份。Antigravity 安装后重新开启会话，
按 Host 正常流程审阅信任和工具权限；安装成功不等同于科研任务验证通过。

## Qualification and publication / 验证与发布

The candidate version is `2.4.0` for npm, PyPI and Cargo. Standalone target scope
remains macOS ARM64, Windows x64, Linux x64 and Linux ARM64, with Linux glibc
2.35+. Package-manager prerequisites remain Node 18+, Python 3.9+ and Rust 1.97+.

Release gates cover installed-Codex regression, save/restart and held-out cases,
AGY complete-output/clean-shutdown evidence, exact-source package/upgrade checks
and four-target distribution. The execution plan distinguishes completed scoped
observations from remaining gates and retains earlier failures. Successful builds
or older-source observations cannot fill a missing gate or establish broad
academic accuracy.

On the named Host candidate, installed Codex regression passes 3/3, a reviewed
note's save/restart journey passes 1/1, and three frozen synthetic held-out cases
pass 3/3. These observations use supplied guidance locations and do not establish
automatic discovery or broad research accuracy. Antigravity 1.3.0 installation
and an authenticated status call complete normally. Supplying its public tool
schemas also enables complete, hash-matched recovery of both saved document
bodies. Its strict status capture and both complete-session recovery checks
still fail; these scoped successes do not satisfy the outstanding AGY gates.
The execution plan retains the exact sources, failures and cleanup evidence.

Frozen source `8fd774a0` passes four-target CLI build/installation, combined
packages, historical and explicit 2.3.0 upgrades, and Cargo archive installation.
Downloaded assets pass the existing exact-source CI and checksum verifier.
The separately dispatched full Native workflow exposes failures in retained
Alpha-only App/product helpers on this stable version; it is not an all-green
workflow or Desktop qualification. The existing standalone CLI release boundary
and the still-failed strict AGY gates remain unchanged.

Publication uses the existing reviewed `main` and immutable-tag workflow after
the release decision. Authorized source synchronization and four-target CLI/Cargo
qualification are complete for the named source. No tag, registry publication, external Marketplace
promotion, Desktop release or announcement is included in that authority.
