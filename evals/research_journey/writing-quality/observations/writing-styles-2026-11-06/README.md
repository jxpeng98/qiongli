## Saving and continuing

The choices ship as shared Host guidance, with a bilingual synthetic example;
they do not add native flags, configuration or a separate preference store.
Requested project persistence uses the existing context maintainer and handoff:
record the active preference's name, language, scope and sample reference in
`Decision Summary`, and retain alternative artifact links in `Completed Artifacts`.
Actual writes use the existing preview/approval/CAS owner, and continuation reads
current saved artifacts. With no supported project save, show the preference and
versions without claiming persistence.

This repository increment retains the examples and adds the reusable guidance.
It does not update an installed Plugin, save a research project's preference or
publish a release.
