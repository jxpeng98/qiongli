## Download Guide

Most users should not download plugin tarballs manually from GitHub's flat asset list.

Rust Lite native assets generated by this release job are scoped to `aarch64-apple-darwin` and carry `bin/qiongli-literature-provider.target.json`; they are not generic multi-platform binaries.

| You use | Recommended path |
|---|---|
| Qiongli npm/npx CLI (`npm-plugin-lite`) | Use `npx qiongli@next install --target all --project-dir "$PWD"`. |
| Codex (`codex-marketplace-plugin`) | Download `qiongli-next-codex-plugin-v1.18.0-beta.3.tar.gz` only on `aarch64-apple-darwin`; the generic marketplace dist ref is not advanced. |
| Claude Code (`claude-code-marketplace-plugin`) | Download `qiongli-next-claude-plugin-v1.18.0-beta.3.zip` only on `aarch64-apple-darwin`; the generic marketplace dist ref is not advanced. |
| Claude Desktop direct plugin (`claude-desktop-direct-plugin`) | Download `qiongli-next-claude-desktop-plugin-v1.18.0-beta.3.zip` as the recommended direct plugin. |
| Claude Desktop/Web skills (`claude-desktop-skill-zip`) | Download `qiongli-next-claude-desktop-skill-core-v1.18.0-beta.3.zip` as the fallback skill ZIP unless you need a different subject ZIP. |
| Claude Desktop literature tools | Download `qiongli-literature-provider-0.2.0-beta.2.mcpb` and pair it with a Desktop skill ZIP when provider calls are required. |
| Zotero Desktop local writes | Download `qiongli-zotero-companion-0.2.2.xpi` and install it from Zotero's add-on manager when local Zotero search/write support is required. |
| Maintainers | Use Codex/Claude plugin tarballs and Claude plugin ZIPs only for manual marketplace artifact checks or direct Claude plugin upload tests. |

The release also includes `qiongli-downloads-v1.18.0-beta.3.md`, `qiongli-downloads-v1.18.0-beta.3.json`, and `qiongli-artifacts-v1.18.0-beta.3.json` to group the asset list by install surface and expose per-target artifact policy.
