# qiongli `v1.15.0-beta.1` Release Notes

Date: 2026-07-04
Stage: Beta

## Highlights

- Clarifies MCP provider status boundaries so `qiongli_literature_search` is the source of truth for
  configured literature providers, while `qiongli_collect_evidence` reports the separate external
  command boundary.
- Raises and standardizes literature search result defaults across Python and MCPB provider paths,
  including review-mode search defaults for broader discovery.
- Documents search completeness limits: provider metadata is not full-text coverage, and full-text
  confidence depends on provider links, Zotero attachments, native platform search, and explicit
  diagnostics.
- Adds native full-text candidate planning and keeps DOI/PDF/OpenAlex access candidates distinct so
  full-text retrieval decisions are traceable instead of inferred from metadata alone.
- Expands Zotero companion support with attachment verification summaries and sanitized local path
  handling for safer local Zotero search/write workflows.
- Fixes beta release install validation for materialized Python payloads whose active skill registry
  lives at `payload/skills/registry.yaml` while runtime resources also create a partial
  `payload/content/skills` mirror.

## Download Guide

Most users should not download plugin tarballs manually from GitHub's flat asset list.

| You use | Recommended path |
|---|---|
| Qiongli CLI | Use `npx qiongli@next install --target all --project-dir "$PWD"` for npm next-channel CLI testing. |
| Codex | Use `codex plugin marketplace add jxpeng98/skillsplace --ref main` and install `qiongli-next`; no manual tarball download required. |
| Claude Code | Use `claude plugin marketplace add jxpeng98/skillsplace@main` and install `qiongli-next`; no manual tarball download required. |
| Claude Desktop direct plugin | Download `qiongli-next-claude-desktop-plugin-v1.15.0-beta.1.zip` for direct plugin install. |
| Claude Desktop/Web skills | Download `qiongli-next-claude-desktop-skill-core-v1.15.0-beta.1.zip` only for manual skill upload. |
| Claude Desktop literature tools | Download `qiongli-literature-provider-0.1.5.mcpb` and pair it with a Desktop skill ZIP when provider calls are required. |
| Zotero Desktop local writes | Download `qiongli-zotero-companion-0.2.2.xpi` and install it from Zotero's add-on manager when local Zotero search/write support is required. |
| Maintainers | Use Codex/Claude plugin tarballs and Claude plugin ZIPs only for manual marketplace artifact checks or direct Claude plugin upload tests. |

The release also includes `qiongli-downloads-v1.15.0-beta.1.md` and `qiongli-downloads-v1.15.0-beta.1.json` to group the asset list by install surface.
