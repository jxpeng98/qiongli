# Qiongli v2.5.1 — automatic installation and DeepSeek diagnostics

This patch improves client selection, recovery during batch installation and
DeepSeek installation diagnostics. Research workflows and MCP tool counts retain
the 2.5.0 contracts.

## Installation / 安装

- Detect installed Codex, Claude, DeepSeek, Antigravity and Pi CLIs when Plugin
  commands omit `--target`. Enter in the main guide selects all detected clients.
  Explicit selections and options retain their compatibility checks.
- Reuse registered or verified Plugin source directories. Fresh Codex/Claude
  exports use separate directories; Antigravity updates recover verified custom
  source paths. Existing Hook settings and user models remain intact.
- Continue with later clients when one installation fails or is declined. The
  final summary distinguishes installed, failed, skipped and not-run clients and
  supplies targeted retry commands. A partial failure still returns nonzero;
  closed input or output failure stops safely.
- Show client/command progress and five-second elapsed-time updates while waiting
  for official package managers.

安装时自动检测常用客户端并选择可验证的已有路径，逐个保留预览与批准。
单个客户端失败或被跳过后继续处理其余客户端，最后统一列出结果与重试方法。

## DeepSeek diagnostics / DeepSeek 分步诊断

- Report twelve numbered stages with start/result, elapsed time and the exact
  failing stage. Registration, package version, content receipt and language
  writes have separate checks; manager exit zero alone is not success.
- Show the actual command, working directory, PATH, environment key names,
  stdin/output policy, timeout, exit code and captured output sizes. Recognized
  manager observations appear after capture; raw output is not echoed or saved.
- Explain the Desktop-owned launcher's profile requirements. Preserve the exact
  package version, profile, registry and arguments in targeted retry guidance.

The maintainer supplied a successful Apple Silicon Mac diagnostic-CLI trace
against DSH 0.2.0-rc.2: package-manager exit zero, verified registration/version/
receipt and completed language write. That trace installed public qiongli@2.5.0;
it is not qualification of new 2.5.1 package bytes or a new-session tool call.
The cause of the earlier intermittent failure remains unconfirmed.

## Compatibility and verification / 兼容与验证

Full MCP retains 35 tools and Lite retains 15. There is no research schema
migration or expansion of write authority. Existing approval, revision/CAS,
source-drift and unmanaged-path refusals remain active. Antigravity and Pi retain
their experimental support limits; Codex remains the primary research Host.

The published target set remains macOS ARM64, Windows x64 and Linux x64/ARM64
(glibc 2.35+). Earlier host-local Linux and cross-built Mac diagnostic packages
had stricter OS requirements; they are not the assets published by this task.
Keep the previous CLI, managed Plugin sources and project/settings backups for
rollback. Changing executables does not reverse research writes.
