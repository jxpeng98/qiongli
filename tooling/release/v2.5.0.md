# Qiongli 2.5.0 — writing contracts and simpler Host installation

This release aligns writing Skills around source-supported argument, clear prose
and the user's requested scope. It also delivers the accumulated Pi adapter,
all-client installation entry and compact Antigravity Skill list.

## Writing / 写作

- Align Discussion and title/abstract guidance with the shared writing contract.
  Direct prose edits no longer require separate Story Spine files or unrelated
  submission metadata. Formal output paths and approved project writes remain.
- Connect the opening question, literature evidence, findings and discussion.
  Distinguish reported facts, this study's results and original author reasoning;
  trace an inference to its premises without pretending a cited source states it.
- Replace universal cluster counts, title formulas and mechanism quotas with
  task-appropriate guidance. Judge analytical depth by the explanation needed for
  the argument, preserving meaningful uncertainty and technical distinctions.
- Cite a meta-analysis for its own pooled results; retain secondary attribution
  when an original study has not been inspected. Background and note claims keep
  their source-support requirements.
- Calibrate the RFS subject profile against its official scope, distinguishing
  local fit advice from verified journal requirements.
- Add a frozen synthetic English literature review and Chinese connected-section
  cohort. Source support, explanation, continuity, language and request fidelity
  remain separate judgments; original failures and prompted repairs are retained.

写作目标是让读者看清证据如何支撑论点、段落如何推进研究问题。保留出处、数值、
限定条件和作者原意，按实际任务选择结构与展开程度。写作改进不构成研究设计质量、
真实全文效果或期刊接受的保证。

## Installation / 安装

- `qiongli install all` installs each detected supported client's Plugin, including
  its Skills and MCP, through the existing per-client installation owners.
  `update all` and `upgrade all` use the same detection and confirmation boundaries.
- Add experimental Pi coding-agent support through `qiongli install plugin --target pi`.
  The package exposes the main Qiongli Skill and `no-qiongli`, with native Full MCP
  through Pi's built-in registration API. Use the official executable on PATH;
  Pi mise shims are not resolved by this adapter.
- Antigravity now exposes the main research Skill and `no-qiongli`; research
  workflows remain internal resources. Existing expanded installations retain
  managed update compatibility.

Pi observations cover official SDK loading, isolated installation, cancellation,
tool discovery and a native status call. Model-driven research and Pi-specific
Windows/macOS behavior remain unqualified. Antigravity remains experimental:
earlier full-session and response-capture gaps are retained. Codex remains the
primary research Host. Installation preserves the user's configured models and
unrelated Host settings.

## Compatibility and rollback / 兼容与回退

Full MCP retains 35 tools and Lite retains 15. This update adds no research schema
migration or expansion of write authority. Existing preview, approval, revision/
CAS, source-drift and unmanaged-installation refusals remain active.

The CLI target set remains macOS ARM64, Windows x64, Linux x64 and Linux ARM64
(glibc 2.35+), with existing Node, Python and Rust package prerequisites. Separate
Host support limits do not establish platform-specific research qualification.

Keep the previous executable, managed Plugin source and project/settings backups
before upgrading from 2.4.0. Reverting executable or Plugin versions does not undo
research writes. Restore a separate backup when necessary; never replace assets
under an already published tag.
