## Decision

The repeatable macOS Alpha.1 acceptance entry point is accepted as automated
engineering evidence. It binds one externally supplied package digest and
source identity to the package receipt, external and embedded manifests,
bundle identity, launcher and canonical binary digests, and an isolated
empty-`PATH` startup. Its receipt contains no machine-local paths and keeps
`publication_allowed: false`.

The optional LaunchServices path is deliberately narrower. A successful
`/usr/bin/open` return records `request-accepted`; it does not claim that the
application process or a displayed window was observed. The implementation
was corrected before this receipt so a fast `--startup-check` exit cannot be
reported as a complete window pass.

This evidence is from a local macOS host and a GitHub-hosted macOS build
runner. It is not a clean-machine, human accessibility, signed-release, or
publication receipt.
