# Qiongli v2.2.1

Qiongli 2.2.1 is a patch to the 2.2 research release. It reorganizes the
English and Chinese installation and usage guides and moves release automation
to Ubuntu 24.04 runners. It adds no research command, tool, receipt format or
new platform target.

穷理 2.2.1 是 2.2 系列的修订版：整理中英文安装与使用文档，并将发布自动化迁移到
Ubuntu 24.04 runner。本版不新增科研命令、工具、收据格式或平台目标。

## Packages and compatibility / 软件包与兼容性

The stable tag is `v2.2.1`. The matching npm, PyPI and Cargo packages are
`qiongli@2.2.1`, `qiongli==2.2.1` and `qiongli 2.2.1`. The four native targets
remain macOS ARM64, Windows x64, Linux x64 and Linux ARM64. Python 3.9+, Node
18+ and Rust 1.97+ remain the respective pip, npm and Cargo prerequisites.
Native release builds use Rust 1.97.0, Python 3.12 and Node 24.
Linux binaries and wheels retain the glibc 2.35+ baseline: Ubuntu 24.04
runners build those artifacts inside an Ubuntu 22.04 environment. Ubuntu 24.04
also installs and checks the assembled packages on both Linux architectures.

Use one installation channel once its package is available:

```sh
npm install --global qiongli@2.2.1
python -m pip install --upgrade "qiongli==2.2.1"
cargo install qiongli --version 2.2.1 --locked
```

The patch preserves the 2.2.0 research data and approval contracts. Existing
projects, captured sources, notes, receipts, Host profiles and selected models
must survive package replacement. An older CLI cannot generally read receipts
created by the new 2.2 research features; changing package versions alone does
not downgrade those projects. Keep a backup before upgrading from 1.x or 2.1.x.
External Marketplace catalog promotion and Desktop installers remain separate.

## Release qualification / 发布验证

The release task requires matching checksums and install receipts for all four
target-native CLI archives, four PyPI wheels, the combined npm package and both
Plugin families, plus Cargo source installation. It verifies upgrade data
retention in disposable environments. This package qualification does not claim
live Host acceptance, academic accuracy across disciplines or a general
project-format downgrade.
