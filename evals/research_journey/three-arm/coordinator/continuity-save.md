# Common post-session decision and save procedure

Coordinator-only until the initial response has ended. Do not expose the followup
task, correction or review criteria to that session. Deliver the following exact
decision through the same save workflow in each arm; preserve the actual returned
candidate unchanged, including any mistakes. A separate coordinator can perform
the save, but record all intervention and approval time consistently in A/B/C.
The save is outside the measured model session; its cost is part of the unit.

> 保存本轮完整返回稿，同时保留输入原稿与来源版本1。当前结果仍是 partial，尚未核查工作量记录、参与者逐字稿和后续追踪。项目默认使用简洁中文；下一次中文修订段落临时采用解释充分的风格，之后恢复简洁。英文保持简洁、正式，不作实质扩写。这是项目内的局部决定，不改变全局设置。保存原稿、候选、来源位置、这一决定和未解决事项，供全新会话继续。

A/B use the Host's normal persistent files and an ordinary entry point; no
Qiongli-specific file names, tool calls or receipts are required. C uses native
capture/consolidation previews and approval/CAS, retaining exact preview and save
receipts. No silent language repair or manually supplied source-support answer is
allowed. If a draft cannot be saved, record the failure and preserve it externally;
do not replace it with another arm's successful draft. The pending followup remains
not completed in the denominator.

Before the fresh session, verify that this arm's stored original, candidate,
source and decision match their pre-save bytes. Put correction.md and task.md in
the newly readable followup directory. Supply only the ordinary entry point in
A/B or registered project ID in C, not saved content or a hidden answer checklist.
Do not overwrite source version 1. Record all added prompts, save actions, byte
bindings, actual times and any deviation from this procedure.
