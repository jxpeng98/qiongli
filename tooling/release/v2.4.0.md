# Qiongli v2.4.0 — traceable sources and clearer research writing

穷理 2.4.0 加强从文献阅读到正文写作的追踪：保留已读材料，定位具体原文，
把正文中的事实和推论分别核查，并在新会话中找回已保存的写作单元。
写作规范覆盖引言、文献综述、方法、结果与讨论，强调易读、具体、连贯的表达。

CLI、Plugin/Skills 和 MCP 是本次交付入口。Codex 是主要科研 Host；
Antigravity CLI 作为实验性适配提供，其验证限制见下文。

## Changes / 变更

- Read an exact passage from a saved source packet with `--json-pointer` /
  `json_pointer`. Pagination addresses decoded UTF-8 text while SHA-256 still
  identifies the complete saved packet. Invalid selectors and stale bindings
  refuse; raw reads preserve their existing behavior.
- Search one bound saved document with `project document search`, or `search_text`
  on the existing Full MCP reader. Literal matches return surrounding context,
  distinct locations and exact readback arguments. Continuation preserves the
  query, scope, revision and source hash. Search does not establish source support
  or absence from unread material.
- Discover saved stage summaries through the existing receipt-backed document
  list, then read or search `context/stage_summaries/STG-*.md` through the same
  bounded reader. A new session can recover saved prose, claim IDs and source
  fingerprints from the project ID. Missing, changed or unsafe summaries do not
  receive usable read arguments; history and original reviews remain intact.
- Identify checkable claims from actual manuscript sentences, captions and notes.
  Keep reported findings and author inferences separate, even when they refer to
  the same passage. Preserve exact locations, source versions and unresolved
  identities through reading notes, synthesis and manuscript claim maps.
- Explain the evidence behind literature comparisons and its relevance to the
  paper's question. Contribution ranking and protocol details must not displace
  substantive explanation. Compare compatible quantities and state meaningful
  differences in populations, outcomes and time frames.
- Use clear, concise English or Chinese throughout drafting. Preserve necessary
  technical terms, premises and qualifications; explain paragraph connections.
  Review source support separately from depth, readability and logical continuity.
  Citation checks include background claims and useful explanatory notes, without
  imposing citation or footnote quotas.
- Recheck affected prose when sources change, retaining previous versions and
  reviews. Distinguish new access, substantive corrections and byte-only changes.
  These are Host-guided research judgments, not automatic semantic verification.
- Add Antigravity CLI Plugin installation and updates through
  `qiongli install plugin --target antigravity` (`agy` is an alias). The Plugin
  provides 22 Skill entries, the native executable and Full MCP, with separate
  source export and official Host registration steps.
- Strengthen observation tooling with frozen inputs, complete output retention,
  matched tool calls, separate answer review and preserved failed attempts. Add
  a credential-free Codex sandbox preflight and explicit 2.3.0 predecessor
  selection for package upgrade checks.

## Antigravity experimental support / 实验性支持

Antigravity CLI support is experimental in 2.4.0. Scoped Antigravity 1.3.0
observations established installation, a normally completed authenticated status
call and hash-matched document-body recovery when public tool schemas were
supplied. Automatic discovery and complete research-session recovery are not
qualified. The Host stream omits the original MCP response envelope; strict
complete-result checks remain failed and are retained for later promotion.
These observations are not a passed academic workflow or IDE qualification.
Codex remains the primary research Host; its checks and all package/upgrade
requirements remain in force.

Antigravity 已验证的范围包括安装、状态调用，以及提供公开工具描述后的文档
正文回读。自动发现、完整科研会话恢复和原始 MCP 响应捕获仍有缺口；主要科研
工作建议使用 Codex。实验性标记不将既有失败改为通过。

Retain the exported source directory while registered, review the Host's normal
trust and tool permissions, and start a fresh session after installation/update.
See [Antigravity installation](../../docs/advanced/plugin-installation.md#antigravity).

## Compatibility and rollback / 兼容与回退

Full retains 35 tools and Lite retains 15; configured user models are unchanged.
There is no research schema migration or expansion of project write authority.
Existing preview, approval, revision/CAS, source-drift and unmanaged-installation
refusals remain active. Summary discovery uses validated consolidation receipts;
other context files and absolute project roots are not exposed by this extension.
Older readers may not support summary recovery and require an authorized fallback.

Target scope remains macOS ARM64, Windows x64, Linux x64 and Linux ARM64 (glibc
2.35+). Package-manager prerequisites remain Node 18+, Python 3.9+ and Rust 1.97+.
Codex/Claude archives and the DeepSeek projection retain their existing owners.

Before upgrading from 2.3.0, retain the previous executable, Plugin source and
project/settings backups. Test on a project copy. Reverting a binary or Plugin
cannot undo research writes or downgrade saved receipt formats; restore a
separate pre-upgrade backup when needed. Upgrade checks establish package
replacement and synthetic fixture retention, not arbitrary project migration.

## Verification scope / 验证范围

The [execution plan](../../docs/superpowers/plans/2026-10-05-v2-4-plugin-quality-release-plan.md)
binds candidate identities, focused native checks, original writing outputs and
installed-session observations, including retained failures. Supplied-source
exercises and model review do not guarantee whole-manuscript quality, automatic
Skill discovery, expert review or source authenticity. Publication uses the
existing immutable-tag workflow: build and verify matching four-target assets
before the GitHub release, then dispatch npm, PyPI and Cargo publication. Package
builds do not substitute for academic review. Desktop and external Marketplace
promotion are outside this release.
