# Task 1 — write from the saved evidence

这是一个虚构材料练习。已提供隔离项目 ID；请使用当前安装的穷理工作流，根据项目
中已保存的材料，撰写中文文献综述片段。研究问题是：指导清单对新人首次装配的
帮助，能否说明他们以后也能独立完成装配？

先取得当前项目与保存材料的位置，读取需要的原文。交付约 500–700 字的正文，围绕
本文问题比较两项研究的具体设计、测量、时间和证据边界；说明它们如何支持或限制
本文的研究问题。加一条有用的解释性注释，重要结论和限制仍放在正文。使用来源
citekey 引用，不要搜索新材料或写入项目。
字数仅计算正文的非空白 Unicode 字符，包括标点和数字，排除括号内的 citekey
引用及注释标记；注释和后面的论断地图不计入正文长度。

正文之后给出紧凑的论断地图，使用既有八列模板，稳定编号从 CLM-001 起；每项
独立论断连接到实际检查的来源版本、字段及必要上下文。说明阅读范围和未解决的
问题，不要将摘录当作整篇全文。原文位置应能逐一回读；找到句子之后还需要判断
它是否支持正文中的论断。
