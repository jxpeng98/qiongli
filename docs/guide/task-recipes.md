# Choose a research task

Describe your material and goal in the Host. Use these requests as a starting point.

| Goal | Example request |
|---|---|
| Narrow a topic | Narrow the research question using these sources; flag unresolved assumptions. |
| Read a paper | Explain this paper's methods, findings, evidence locations and limitations. |
| Literature review | Plan the search, then extract and synthesize evidence from the available papers. |
| Study design | Check this design against the question, available data and approved protocol. |
| Write | Draft this section from the approved analysis, preserving numbers, sources and uncertainty. |
| Research code | Implement this method and check statistical validity and reproducibility. |
| Submission or revision | Map reviewer comments to manuscript locations and propose responses. |
| Fix one finding | Resolve I8:P1-01 in this candidate and check the affected results. |
| Stage handoff | Summarize this stage with sources, decisions, changes and open questions. |

## Journal decisions

For a chosen journal, request a check of its current requirements. For recommendations, supply the manuscript first. See [journal fit and review](using-agent-skills.md#journal-fit-and-pre-submission-review).

## Save and continue

Formal projects save through previews, approval and revision checks. Carry claim IDs, citekeys, source locations and method limits forward. Summaries preserve original files; you select and delete files yourself.

For discussion only, use [reply-only](../advanced/agent-skill-collaboration.md#reply-only). Find task IDs and outputs in the [Skills reference](../reference/skills.md), or research routes in [paper-type examples](../examples/paper-type-playbooks.md).
