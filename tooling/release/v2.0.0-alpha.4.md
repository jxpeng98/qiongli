# Qiongli v2.0.0-alpha.4 Private Tester Candidate Notes

Status: private exact-source tester candidate. Distribution is limited to an
authenticated GitHub Actions artifact retained for three days.
`publication_allowed=false`.

状态：私有、精确源码绑定的测试候选版本。仅通过需要认证的 GitHub Actions artifact
分发，保留三天。`publication_allowed=false`。

This candidate is not a Git tag, GitHub Release, update-channel publication,
package-manager release, or public announcement. The latest public Qiongli 2
prerelease remains `v2.0.0-alpha.1`.

本候选版本不是 Git tag、GitHub Release、更新通道发布、包管理器版本或公开公告。
当前最新的 Qiongli 2 公开预发布版本仍为 `v2.0.0-alpha.1`。

## Candidate scope / 候选范围

- One merged `2.x` product source must produce the macOS arm64, Windows
  x86_64, and Linux x86_64 candidates.
- The candidate packages the current native App, CLI, Plugin/Skills, Lite/Full
  MCP, Graph v1, migration/recovery, and Zotero product spine for rapid tester
  feedback.
- Existing provenance-bound packaging and installation-lifecycle owners are
  reused. No second installer, builder, receipt format, or release pipeline is
  introduced.
- Installation and replacement are manual. No automatic-update metadata is
  advertised for this candidate.

- macOS arm64、Windows x86_64 与 Linux x86_64 候选产物必须来自同一个已合并的
  `2.x` 产品源码提交。
- 候选版本打包当前原生 App、CLI、Plugin/Skills、Lite/Full MCP、Graph v1、
  migration/recovery 与 Zotero 产品主干，用于快速测试反馈。
- 复用现有的 provenance-bound 打包与安装生命周期所有者，不新增第二套 installer、
  builder、receipt 格式或发布流水线。
- 安装与替换均为手动操作；本候选版本不发布或宣传自动更新 metadata。

## Closed target set and trust / 封闭目标集合与信任边界

- macOS arm64: ZIP and DMG; ad-hoc signed and not notarized. Gatekeeper may
  require the per-app **Open Anyway** flow.
- Windows x86_64: unsigned portable ZIP; SmartScreen, Smart App Control,
  antivirus, or enterprise policy may warn or block it.
- Linux x86_64: AppImage and portable ZIP; the host must provide the runtime
  facilities declared by the package.
- No other operating system or architecture is part of this candidate.

- macOS arm64：ZIP 与 DMG；使用 ad-hoc 签名且未公证。Gatekeeper 可能要求对该
  App 执行“仍要打开”。
- Windows x86_64：未签名的 portable ZIP；SmartScreen、Smart App Control、
  杀毒软件或企业策略可能发出警告或阻止运行。
- Linux x86_64：AppImage 与 portable ZIP；宿主系统必须提供产物声明的运行条件。
- 本候选版本不包含其他操作系统或架构。

Do not disable global operating-system security controls or import a
self-signed Windows root certificate.

请勿关闭全局操作系统安全机制，也不要导入自签名 Windows 根证书。

## Qualification and verification / 资格与验证

The candidate is usable as test evidence only after all of the following bind
the same merged product source and exact bytes:

1. local release readiness completes without publishing;
2. an explicit full Native CI run succeeds for Linux, macOS, Windows, Lite,
   package, packaged-product, and candidate jobs;
3. Community Alpha promotion rebuilds and aggregates the three targets with
   publication authorization left false;
4. the downloaded aggregate is independently checked for its closed file
   inventory, byte sizes, SHA-256 values, source/version fields, Native CI run,
   promotion attempt, and candidate-set digest.

只有以下步骤全部绑定同一个已合并产品源码及精确字节后，候选版本才可作为测试证据：

1. 本地 release readiness 在不发布的前提下完成；
2. 显式执行的完整 Native CI 中，Linux、macOS、Windows、Lite、package、
   packaged-product 与 candidate jobs 全部成功；
3. Community Alpha promotion 在发布授权保持 false 时重新构建并聚合三个目标；
4. 独立核对下载后的 aggregate，包括封闭文件清单、字节数、SHA-256、源码/版本、
   Native CI run、promotion attempt 与 candidate-set digest。

Green CI and successful aggregation are evidence only. They do not authorize a
tag, Release, public upload, update-channel mutation, or announcement.

绿色 CI 与成功聚合仅构成证据，不授权创建 tag、Release、公开上传、修改更新通道或公告。

## Explicit non-claims / 明确不承诺的范围

- No public-download, automatic-update, package-manager, production-signing,
  notarization, Authenticode, Stable, or milestone-exit claim.
- No claim that unfinished `GOV-413`, `GOV-417`–`GOV-418`, `PLT-401`–`PLT-408`,
  or `SEC-401`–`SEC-405` work is complete.
- No production publisher trust or support for targets outside the closed set.
- No publication or announcement authority inferred from an edit, commit,
  merge, successful check, artifact, or prior Alpha 3 receipt.

- 不承诺公开下载、自动更新、包管理器发布、生产签名、公证、Authenticode、Stable
  资格或里程碑退出。
- 不声称未完成的 `GOV-413`、`GOV-417`–`GOV-418`、`PLT-401`–`PLT-408` 或
  `SEC-401`–`SEC-405` 已经完成。
- 不提供生产级发布者信任，也不支持封闭目标集合之外的平台。
- 不从编辑、提交、合并、成功检查、artifact 或历史 Alpha 3 receipt 推导发布或公告授权。

## Replacement and rollback / 替换与回滚

Back up the Qiongli project and global v2 state before testing. Replace this
candidate manually. If it fails, remove only receipt-owned installed payload,
preserve user projects and unmanaged state, and reinstall a retained previous
package when one is available. An invalid or expired candidate must be rebuilt
from a fresh exact source; its artifact or evidence must never be rewritten in
place.

测试前请备份 Qiongli 管理的项目状态和全局 v2 状态。本候选版本仅支持手动替换。
如测试失败，只移除 receipt-owned 的已安装 payload，保留用户项目与非托管状态，并重新
安装仍有保留的前一 package。无效或过期候选必须从新的精确源码重新构建，不得原地
改写 artifact 或证据。

For the general rollback procedure, see `tooling/release/rollback.md`.
