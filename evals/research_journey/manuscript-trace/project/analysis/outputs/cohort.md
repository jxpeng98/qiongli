# OUT-1 — Synthetic study output, not published research

## Methods
The current study is an observational cohort of 240 applicants in fictional Mereton. Attendance at assisted appointments was voluntary, not randomized. We linked the initial application and an eight-week follow-up. Independent return use means a later portal visit completed without staff or family help, as self-reported by the applicant. No adjusted model was run. This is a complete-case descriptive table; it cannot identify an assistance effect.

## Table 1
| Initial appointment | Followed applicants | Reported independent return use |
|---|---|---|
| Assisted | 120 | 48 (40%) |
| Not assisted | 120 | 72 (60%) |

## Table note
A further 30 applicants had no follow-up response and are excluded from these 240 complete cases. The table does not break missing responses down by appointment group. Independent return use differs from any return use or initial submission. No confidence interval or significance test was computed.
