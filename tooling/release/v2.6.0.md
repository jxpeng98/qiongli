# Qiongli v2.6.0 — writing quality and saved research continuity

This candidate brings the writing and research-continuity work since v2.5.3 into
the native CLI and shared Plugin/Skills content. It is prepared locally;
publication and the four-target distribution qualification remain separate.

## Writing / 写作

- Separate language polishing from source-bound meaning review in G4/J2. An
  Antigravity return is a candidate revision: check facts, terms, citations,
  argument structure and necessary qualifications before adopting it.
- Preserve supported conclusions and correct original prose. Remove repeated
  defensive setup without deleting study boundaries or turning associations,
  cross-study explanations and theoretical propositions into stronger claims.
- Carry comparison subjects, precise measures and reasoning across consecutive
  paragraphs, sections and Chinese/English versions. Added detail must serve the
  requested passage rather than satisfy an unrelated completeness checklist.
- Offer optional concise and explanatory styles, plus user-provided samples.
  Keep alternatives and scoped preferences; a paragraph override does not change
  the project default or the user's model. Existing preview/approval/CAS owners
  handle requested saves.

中文写作以自然、简洁和论证完整为共同目标；“简洁流畅”和“细节展开”可按任务选择。
原文正确时可以保留，不必为了显示修改而重写。语言偏好、原文核对和学术判断分别记录。

## Research continuity / 研究衔接

- Resume current research state and stage handoff with the new read-only
  `project context read` entry. It checks registered identity, revision and
  semantic freshness without requiring a Graph/catalog rebuild.
- Read saved stage summaries through the existing document binding/read owners;
  preserve cancelled captures and distinguish saved records from current source
  verification. Bound source reads and guidance delivery while keeping incomplete
  text or image coverage explicit.
- Reuse evaluation helpers for frozen writing inputs, meaningful length counts,
  bilingual Antigravity returns and cross-session recovery. Public-paper runs and
  anonymous feedback remain scoped observations, not a general quality ranking.

```sh
qiongli project show --project-id <prj_id> --json
qiongli project context read --project-id <prj_id> \
  --expected-project-revision <revision> --artifact stage-handoff --json
```

## Provider setup / 文献服务配置

`provider setup` and CLI-hosted MCP provider configuration share the native,
one-save loopback page. Blank secret fields keep existing values; settings
revision and explicit approval remain required. The current secret adapter uses
macOS Keychain; other platforms refuse secret writes instead of saving plaintext.
This work does not change research model selection.

## Verification and rollout / 验证与发布

The [execution plan](../../docs/superpowers/plans/2026-10-05-v2-4-plugin-quality-release-plan.md)
and [closeout observation](../../evals/research_journey/writing-quality/observations/release-closeout-2026-11-06/README.md)
record actual checks, failures, retries and pending human evidence. Complete
public-source analytical examples do not substitute for a private manuscript or
disciplinary expert acceptance; unrecorded editing time remains unknown.

No project-schema migration or model-default change is introduced. Full/Lite
retain 35/15 tools. Codex remains the primary research Host; Antigravity/Pi remain
experimental. Distribution targets remain macOS ARM64, Windows x64 and Linux
x64/ARM64 (glibc 2.35+). Local current-target package checks do not establish the
other targets or live installation in every Host.

After an approved release, update through the original CLI installation channel,
refresh Plugin/Skills and start a new Host session. Keep the previous executable,
Plugin sources and research/settings backups for rollback. Replacing the CLI
does not undo research writes. Cache cleanup covers only identified regenerable
build output and preserves release assets, source data and evaluation evidence.
