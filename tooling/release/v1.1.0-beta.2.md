## Download Guide

Most users should not download plugin tarballs manually from GitHub's flat asset list.

| You use | Recommended path |
|---|---|
| Codex | Use `codex plugin marketplace add jxpeng98/skillsplace --ref main`; no manual tarball download required. |
| Claude Code | Use `claude plugin marketplace add jxpeng98/skillsplace@main`; no manual tarball download required. |
| Claude Desktop/Web skills | Download one `qiongli-claude-desktop-skill-<subject>-v1.1.0-beta.2.zip` asset. Start with `qiongli-claude-desktop-skill-core-v1.1.0-beta.2.zip` unless you need a subject package. |
| Claude Desktop literature tools | Download `qiongli-literature-provider-0.1.0.mcpb` and pair it with a Desktop skill ZIP when provider calls are required. |
| Gemini CLI | Download `qiongli-gemini-extension-v1.1.0-beta.2.tar.gz` only when installing from a release artifact. |
| Maintainers | Use Codex/Claude plugin tarballs only for manual marketplace artifact checks. |

The release also includes `qiongli-downloads-v1.1.0-beta.2.md` and `qiongli-downloads-v1.1.0-beta.2.json` to group the asset list by install surface.
