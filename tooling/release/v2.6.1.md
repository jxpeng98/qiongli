# Qiongli v2.6.1 — restore macOS release builds

This patch carries the writing, research-continuity and focused CI improvements
described in [v2.6.0](v2.6.0.md), whose release stopped before publication.

## Fix / 修复

GitHub retired its macOS 14 runners on November 2, 2026. The v2.6.0 distribution
run could not start its macOS ARM64 job, so the release correctly stopped before
creating a GitHub Release or dispatching registry publication.

- Move CLI builds, combined-package install checks, Cargo qualification and
  public Cargo install checks to the supported `macos-15` ARM64 runner.
- Keep all four distribution targets, native install and upgrade checks, and
  exact-source publication gates. The workflow contract test now requires the
  supported macOS image throughout these stages.
- Preserve the immutable v2.6.0 tag; the repaired source uses the new v2.6.1 tag.

本次修复发布流程中已停用的 macOS 14 构建环境，统一使用 macOS 15 runner。
四目标构建、安装和升级验证保持完整；写作规则、研究数据和用户模型配置没有改动。

## Verification and recovery / 验证与恢复

The [execution plan](../../docs/superpowers/plans/2026-10-05-v2-4-plugin-quality-release-plan.md)
records the failed run, regression checks and candidate qualification. The release
workflow must still qualify the exact tag on all four targets before publication.
Changing the runner does not by itself establish older macOS runtime compatibility.

Update through the original installation channel and refresh Plugin/Skills.
Keep the previous executable, Plugin sources and research/settings backups for
rollback; replacing the CLI does not undo research writes.
