# Qiongli v2.1.1

Qiongli 2.1.1 improves multi-Host installation and adds English/Chinese Skill
metadata selection. Host models, research-write approval and revision checks
remain unchanged.

穷理 2.1.1 改进多 Host 安装，并支持选择英文或中文 Skill 描述；保留用户配置的
模型以及研究写入的预览、确认与版本核验。

## Installation changes / 安装改进

- The interactive guide accepts multiple Hosts using comma/space-separated
  numbers or names, and `all`. Existing `3`/`both` still selects Codex and
  Claude Code together.
- DeepSeek installation uses the official DSH 0.2+ Plugin manager, previews the
  selected profile and exact npm version, asks for trust confirmation and checks
  registration after installation. Use **Official npm registry** and
  **`qiongli@2.1.1`** in the Desktop Add plugin dialog, or run:

```sh
dsh plugin --profile desktop add qiongli@2.1.1
```

Replace `desktop` with your intended profile. DSH upgrades use its own
remove/install manager; retain your profile and model settings.

## Skill language / Skill 语言

The installation guide offers Auto, Chinese and English. Plugin and standalone
Skill commands accept `--language auto|zh|en`; updates retain the selected
language when the option is omitted. Auto reads locale environment variables
before OS preferences and falls back to English for unsupported locales.
All 22 entries share concise English/Chinese descriptions. Invocation names,
workflow bodies, resource paths and approval boundaries remain unchanged.

安装向导支持自动、中文、英文，命令可使用 `--language auto|zh|en`；更新时省略
该选项会保留已选语言。语言选择只调整描述等元数据，不改变调用名与工作流正文。
DSH loads saved preferences through its official profile context. After changing
language, restart the corresponding profile or Desktop client. A new chat alone
is insufficient; changing the client UI language does not rewrite installed Skills.

## Packages / 安装渠道

```sh
npm install --global qiongli@2.1.1
python -m pip install --upgrade "qiongli==2.1.1"
cargo install qiongli --version 2.1.1 --locked
```

Choose one channel. GitHub Assets supplies standalone macOS ARM64, Linux x64
(glibc 2.35+) and Windows x64 archives. Verify `SHA256SUMS` before extraction.
npm needs Node 18+, PyPI Python 3.9+, and Cargo Rust 1.97+.

## Qualification limits and rollback / 验证范围与回退

Development checks include isolated official DSH 0.2.0-rc.2 sessions on macOS
ARM64 with 22 Skills, both languages and 32 Full MCP tools. These observations
are separate from frozen release-packet qualification. Windows/Linux system
language detection, real user client refresh and real model collaboration remain
unverified. The earlier broad CLI library run had three failures subsequently
fixed with focused checks; a final complete 236-case rerun was not established.
Tag-bound automation requires fresh three-platform distribution and combined
package checks before GitHub and npm/PyPI/Cargo publication. Dispatch acceptance
alone does not prove publication or broader research acceptance.

To roll back, install the previous CLI package and export/re-enable its Plugin.
DSH uses its own remove/install manager with the prior version. Retain research
records, profiles and caches. This release does not authorize their deletion or
external Marketplace promotion.
