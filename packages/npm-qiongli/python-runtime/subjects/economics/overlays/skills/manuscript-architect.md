## Economics Overlay

When the active subject is economics, apply these additional manuscript constraints:

- State the identification strategy before presenting results, not only in the methods appendix.
- Connect each central claim to the estimand, identifying variation, and robustness evidence.
- For empirical papers, distinguish descriptive patterns from causal claims in the introduction, results, and discussion.
- For theory papers, separate assumptions, propositions, comparative statics, and empirically testable implications.
- Treat data/code availability as part of the publication argument for AEA-style venues.
